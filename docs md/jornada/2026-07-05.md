# Jornada — 2026-07-05

### Resumen ejecutivo
Implementación de la importación automatizada de catálogos Excel a SQLite/EF Core con soporte para perfiles fiscales (TaxProfile). Alineación del lector de código de barras y flujos de cobro en caja rápida, e integración de impresión térmica ESC/POS con autodetección de impresoras de Windows.

### Cambios en la app
- Importador de Catálogo Excel: Bootstrapping e importación por lotes para normalizar y cargar productos de planillas Excel directos a SQLite.
- Impresión Térmica ESC/POS: Implementación del adaptador `InstalledPrinterProvider` para buscar e interactuar con impresoras físicas de Windows.
- Caja rápida alineada: Acoplamiento de la lectura de códigos de barra directamente con el flujo de transacciones de cobro en caja.
- Base de datos extendida: Nuevas entidades de base de datos (`ProductImportBatch`, `ProductImportLine`, `TaxProfile`, `CatalogItemType`) con migraciones aplicadas.
- Registro de Skills: Documentación de directrices de catálogo y base de datos en `.skills/`.
