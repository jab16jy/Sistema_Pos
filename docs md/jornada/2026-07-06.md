# Jornada — 2026-07-06

### Resumen ejecutivo
Robusto fortalecimiento de manejo de excepciones y resiliencia en la UI de WPF (exception hardening). Implementación de persistencia para configuración SMTP y flujos de notificación por WhatsApp (Desktop/Web fallback). Adición de buscador interactivo (autocompletado debounced) en caja rápida, comandos de exportación a PDF de facturas y flujo seguro para la cancelación de ventas por administrador.

### Cambios en la app
- Exception Hardening: Auditoría y protección sistemática de comandos asíncronos y ciclo de vida de ViewModels para prevenir cierres inesperados de la aplicación.
- Autocompletado Predictivo: Búsqueda reactiva en caja con temporizador de retardo (debounce) para no saturar SQLite al escribir rápido.
- Cancelación de Ventas: Caso de uso `CancelSaleUseCase` que devuelve productos a inventario, genera movimientos y valida el rol del administrador.
- Persistencia SMTP: Migración y almacenamiento de credenciales SMTP directamente en la base de datos SQLite de ajustes generales.
- Redirección Inteligente de WhatsApp: Detección y lanzamiento del cliente WhatsApp Desktop (URI), cayendo a la interfaz Web si la aplicación no está instalada.
- Diálogos y PDF: Exportación nativa de comprobantes de facturas a PDF con selector de archivos interactivo.

### Decisiones relevantes
- SMTP en SQLite: Almacenar la configuración en base de datos permite cambiar los servidores y passwords directamente desde la UI de ajustes sin requerir configurar variables de entorno en el equipo local del cliente.
- Debouncing en Autocomplete: Limitar las consultas a SQLite con un delay (de 300ms a 500ms) garantiza la fluidez de la interfaz ante entradas rápidas del usuario en caja.
- Fallback WhatsApp: Priorizar el protocolo `whatsapp://` frente a la web para agilizar la interacción si se utiliza la versión de escritorio de Windows.
