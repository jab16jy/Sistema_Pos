# Enhance report exports

## Summary

Make report exports more useful for operational review by adding detailed Excel sheets and reducing report PDF body content to 75% scale.

## Problem

The current workbooks expose summary values but do not provide a consolidated explanation of each collection component or a detailed period comparison. Report PDFs can be difficult to scan when their body content uses the default scale.

## Outcome

- Operational workbooks include a detailed collection sheet with calculations, physical-cash impact, and operational interpretation.
- Profitability workbooks include a detailed current-versus-prior period comparison.
- Operational and profitability PDF body content renders at 75% scale while retaining the existing page header and footer.
